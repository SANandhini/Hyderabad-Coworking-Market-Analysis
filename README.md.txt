# Hyderabad Coworking Market Analysis

## Project Overview

This project analyzes coworking spaces across Hyderabad to identify suitable locations for business expansion.

The analysis focuses on:

- Competitor Analysis
- Market Trends
- Pricing Analysis
- Seat Capacity Analysis
- Location Evaluation

## Objectives

- Identify high-demand coworking locations
- Compare pricing strategies
- Analyze competitor presence
- Recommend suitable expansion areas

## Tools Used

- Python
- Pandas
- Matplotlib
- Jupyter Notebook
- Excel

## Dataset

The dataset contains:

- Company Name
- Location
- Seat Capacity
- Monthly Price

Note:
This dataset is anonymized and used for educational and portfolio purposes.

## Analysis Performed

1. Data Cleaning
2. Exploratory Data Analysis
3. Pricing Comparison
4. Location Analysis
5. Expansion Recommendations

## Key Insights

- HITEC City shows the highest coworking concentration.
- Gachibowli offers strong business demand.
- Madhapur provides balanced pricing and accessibility.
